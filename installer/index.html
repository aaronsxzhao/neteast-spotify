02 / MUSIC DESTINATION 未连接

连接你自己的 Spotify

每个人使用自己的开发者应用，不共享别人的配额。这一步只需配置一次。

跟着完成一次应用设置
  1. 打开你的开发者后台。

    用自己的 Spotify 账号登录。开发模式要求应用所有者拥有有效 Premium。

    打开 Spotify 开发者后台 ↗
  2. 选择 Create app（创建应用）。

    App name 填 My Daily Relay；描述填 Sync my own daily music recommendations。Website 如为选填可留空。

  3. 填写 Redirect URI（回调地址）。

    完整复制下面地址，添加并保存，不要改成 localhost，也不要多加斜杠。

    http://127.0.0.1:18787/auth/spotify/callback
  4. API / SDK 只勾选 Web API。

    阅读并同意 Spotify 条款，保存应用。若出现 Users and Access，确认你自己的 Spotify 登录邮箱在允许用户列表中。

  5. 打开 Settings，复制 Client ID。

    Client ID 是应用标识，不是密码。不要复制 Client Secret。

授权页面报错怎么办？

Redirect URI 错误：回到应用设置，逐字检查上面的地址。403：检查 Premium、允许用户和 Client ID 是否属于你。拒绝授权：重新点连接。冷却：等待指定时间，不要反复重试。

03 / YOUR CLOUD 未授权

确认一次 GitHub 授权

使用你自己的 GitHub 账号。不需要创建仓库、填写 Secrets 或编辑工作流。

这次授权允许什么？

安装助手使用 GitHub 官方 CLI，申请仓库和工作流权限，以创建你的专属仓库、上传程序和加密凭证、启动定时任务。授权范围可能覆盖你有权限的其他仓库，但本助手只操作它创建并校验归属的 Daily Relay 仓库。

GitHub 登录令牌保存在此电脑的独立配置目录（仅当前用户可读，未使用系统钥匙串）；音乐凭证和加密密钥写入你自己的 GitHub Secrets。项目作者不会收到它们。请只在自己的可信电脑上使用。

打开 GitHub 验证页，输入此一次性验证码并确认授权：

打开 GitHub 授权页 ↗

请确认浏览器中登录的是你自己的账号。完成后回到此页面，会自动检测。

在你的账号下创建专属仓库和私密 Spotify 歌单，自动配置每天的同步及失败续跑。

私有仓库的额度与账号其他项目共享；超额可能暂停或计费，取决于你的 GitHub 账单设置。助手不会启用付费额度。公开仓库也绝不会包含明文凭证。
