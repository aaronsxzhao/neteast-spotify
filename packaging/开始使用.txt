Daily Relay · 朋友自助安装版（macOS 测试版）

1. 解压 ZIP，将 Daily Relay.app 拖到“应用程序”或你自己的文件夹。
2. 双击 Daily Relay.app，安装助手会在浏览器打开。
   地址中的 127.0.0.1 / localhost 是你自己的电脑，不是分享者的电脑。无需手输网址，也不用让分享者保持开机。以后再次双击 App 即可管理。
3. 跟随页面：网易云扫码 → 创建你自己的 Spotify 应用并授权 → GitHub 一次性授权 → 开启每日同步。
   两个音乐账号连接好后，也可先点“立即同步一次”，不需要 GitHub。本机同步时请保持 App 运行；只有开启云端后，关机仍可每天自动同步。
4. 页面确认实际同步日期和曲目数量后，即可退出助手并关机。仅显示“部署完成”不代表首次同步成功。

无需安装 Node.js、Git、GitHub CLI，也不需要终端。
Spotify 开发模式要求你自己的应用所有者账号拥有有效 Premium；应用创建仍需本人在 Spotify 后台完成，助手提供逐步说明。

首次打开可能被 macOS 拦截：本测试版未经过 Apple 公证。确认安装包来自你信任的人后，先尝试打开，再到“系统设置 → 隐私与安全性”按系统提示允许打开。不要关闭系统安全保护。如果公司电脑禁止未公证应用，请联系管理员或等待正式签名版。

Apple Silicon（M1/M2/M3/M4 等）使用 arm64 包；Intel Mac 使用 x64 包。二者不要混用。

所有账户与仓库都是你自己的。GitHub CLI 授权令牌会保存在此电脑的专属私密目录；音乐凭证存入你自己的 GitHub Secrets。作者不会收到凭证。
私有仓库使用账号附带的 Actions 额度，超额规则由你的 GitHub 账单设置决定；公开仓库的标准运行免费。自动任务可能延迟，登录可能失效，Spotify 可能要求冷却；助手无法保证每天准点或零限流。

配置目录：~/Library/Application Support/Daily Relay
不要分享该目录，或将它放入公开仓库。换电脑前请安全备份其中的状态与加密密钥。
停止使用：在安装助手中“暂停自动同步”。仅删除 .app 不会停止 GitHub 上的定时任务。
端口冲突：本助手使用 127.0.0.1:18787；关闭占用该端口的程序后重新打开。
